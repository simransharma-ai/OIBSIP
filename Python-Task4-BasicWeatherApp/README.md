# Basic Weather App

## Overview

This project is a Python-based Weather App developed as part of the OASIS INFOBYTE Python Programming Internship.

The application allows users to search weather information using a city name or ZIP code. It displays current weather details, hourly forecast, 5-day forecast, and supports Celsius/Fahrenheit conversion.

## Features

### Beginner Features

- Search weather by city name
- Search weather by ZIP code
- Current temperature
- Temperature in Celsius and Fahrenheit
- Humidity
- Weather condition
- Wind speed
- Empty input validation
- Invalid city handling
- Invalid API key handling
- Network timeout handling

### Advanced Features

- Tkinter GUI
- Weather icon display
- Next 6 hours forecast
- 5-day weather forecast
- Celsius/Fahrenheit toggle
- Error messages displayed in GUI
- Automatic location detection using IP location

## Technologies Used

- Python
- Tkinter
- Requests
- Pillow
- OpenWeather API
- IPInfo
