# Voice Assistant

## Overview

This project is a Python-based Voice Assistant developed as part of the OASIS INFOBYTE Python Programming Internship.

The assistant can listen to voice commands using a microphone, understand basic user intent, and respond using text-to-speech.

## Features

### Beginner Features

- Voice input using SpeechRecognition
- Text-to-speech response using pyttsx3
- Greeting command
- Current date
- Current time
- Web search
- Error handling for unrecognized speech

### Advanced Features

- Free-form command understanding
- Email sending using SMTP
- Reminder with audible alert
- Live weather information
- General knowledge questions
- Custom commands
- Open websites such as Google, YouTube, and GitHub
- Open Windows applications such as Calculator and Notepad

## Technologies Used

- Python
- SpeechRecognition
- pyttsx3
- PyAudio
- NLTK
- Requests
- SMTP
- Open-Meteo API
- Wikipedia REST API
